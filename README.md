# 訓練場：第一人稱射擊原型

## 遊戲簡介
一款原創的 3D 第一人稱射擊瀏覽器原型。每回合會在小型競技場隨機刷新 5–20 名簡易 BOT，擊敗所有對手即可贏得回合。

## 操作方式
- `W` `A` `S` `D`：移動
- 滑鼠：瞄準
- 滑鼠左鍵：射擊（按住可連射）
- `R`：重新裝填
- `Esc`：暫停；按畫面按鈕繼續

## 功能
- Three.js 3D 場景、第一人稱視角與滑鼠控制
- 每回合隨機刷新 5–20 名 BOT，並在場地內分散生成
- 有飛行時間、可見曳光與輕微下墜的敵我彈丸；命中會受掩體阻擋
- 命中判定、生命值、彈藥與回合計時
- 勝負畫面與重新開始

## 執行
用桌面瀏覽器開啟 `index.html`。遊戲從 jsDelivr 載入 Three.js，因此首次開啟時需要網路連線；若瀏覽器限制本機檔案的 ES Module，請在此資料夾啟動本機靜態伺服器後開啟頁面。
